Demo profile pictures. Put one image per demo person here, named after the person, then run `npm run seed`:

    sofia.jpg  marco.jpg  alex.jpg  giulia.jpg  luca.jpg  anna.jpg  tom.jpg  mei.jpg

(.jpg, .jpeg, .png or .webp). The seed crops each to a square, converts it to webp and stores it in the database.
Re-run the seed any time to replace a picture.
